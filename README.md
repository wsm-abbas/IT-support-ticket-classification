# IT Support Ticket Classification

A small project that sorts IT support tickets into an issue type
(network, account access, hardware, software, email) so they can be sent to
the right team. I compare a simple TF-IDF + logistic regression model with a
fine-tuned transformer (DistilBERT) to see whether the bigger model is
actually worth it for short, fairly repetitive text like this.

## Tools

Python, pandas, scikit-learn, Hugging Face Transformers (PyTorch).

## Setup

```bash
python -m venv .venv
source .venv/bin/activate      # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## How to run

`data/tickets.csv` and the trained baseline are already included, so you can
skip straight to the baseline or transformer step. To rebuild from scratch:

```bash
python src/make_data.py          # creates data/tickets.csv (fake tickets)
python src/baseline.py           # TF-IDF + logistic regression
python src/transformer_model.py  # DistilBERT (slow on CPU)
python src/compare.py            # side by side table
```

## About the data

The tickets in `data/tickets.csv` are generated by `src/make_data.py`. They are
not real, so please don't read too much into the scores. To use real tickets,
put a CSV in `data/tickets.csv` with a `text` column and a `category` column
(a `team` column is optional) and skip the first step.

## Results

Scores on the 600 held-out tickets (20% split). The data is generated, so the
numbers are high and mostly show the pipeline works.

| Model | Accuracy | Macro F1 | Train time (s) |
|-------|----------|----------|----------------|
| TF-IDF + logistic regression | 0.975 | 0.975 | 0.1 |
| DistilBERT | not run yet | not run yet | |

The baseline is already trained and saved in `models/tfidf_logreg.joblib`.
DistilBERT needs to download weights from Hugging Face, so run
`python src/transformer_model.py` yourself and then `python src/compare.py`.
